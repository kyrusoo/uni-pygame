## Features
* **Precise Control (Focus Mode):** Holding `Left Shift` reduces player movement speed and displays a micro-hitbox for precise dodging.
* **Complex Bullet Streams:** Features dynamic, time-based mathematical spiral bullet patterns generated by the boss.
* **Data Persistence (High Score Saving):** Safely loads and updates your all-time high score using external file storage.
* **Dynamic HUD:** Real-time visual user interface tracking player life count, running score, and a responsive boss health bar.
* **Deep Space Starfield:** A modularly generated, multi-layered vertical scrolling starfield background creating a 3D depth illusion.

## Technologies Used
* **Language:** Python 3.x
* **Library:** Pygame (Graphics, Inputs, Core Game Loop, and Vector Math)
* **Data Management:** JSON (For persistent data tracking)

## Project Structure
The project is built using Object-Oriented Programming (OOP) and strict modular file separation:
```text
bullet_hell/
├── assets/
│   └── spaceship.png      # 32x32 Player spaceship sprite
└── game/
    ├── main.py            # Director: Handles game loops, states, and collisions
    ├── settings.py        # Constants: Global configuration variables and paths
    ├── player.py          # Player Class: Handles ship inputs, movement, and hitbox
    ├── boss.py            # Boss Class: Controls enemy behaviors and shooting states
    ├── bullets.py         # Bullet Classes: Dictates player/enemy projectile vectors
    └── map.py             # Map Class: Manages scrolling background and star data
